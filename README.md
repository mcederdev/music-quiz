# Track Night

Marketing site for Track Night, a music quiz where everyone plays on their phone.
Served by GitHub Pages at https://mcederdev.github.io/music-quiz/.

- `index.html`: landing page and support/FAQ (`#support`)
- `privacy.html`: privacy policy. Update it whenever the app starts collecting something new.
- `icon.svg` is the source for the PNG icons; `og-image.png` is the 1200x630 share image.

The app's code lives in a separate private repository.
